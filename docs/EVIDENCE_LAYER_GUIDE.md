## 1. Provenance Schema

Every calculation output generated by domain engines produces an immutable proof record in `ai_evidence`:
- `evidence_code`: Unique evidence identifier (e.g. `UNIFIED_AI_CONTEXT_PROOF`, `TAX_OLD_VS_NEW_PROOF`).
- `source_engine`: Originating domain engine (`TaxCalculationEngine`, `EstateHealthService`, `GoalPlanningService`).
- `source_engine_version`: Engine version string (`1.0.0`).
- `rule_version`: Rule version string (`1.0.0`).
- `calculation_hash`: 16-character SHA-256 calculation hash computed from raw inputs/outputs.
- `correlation_id`: Unique tracing ID (`corr_ev_1785245788344`).
- `proof_data_json`: Raw inputs, formula parameters, and output metrics.
