# Operational Support Guide

## Support Channels & Diagnostics
- **Developer Diagnostic Console**: Access `/developer-diagnostics` in UI or `GET /api/v1/platform/registry`.
- **Exporting Diagnostic Telemetry**: Click "Export Diagnostics JSON" in Diagnostic Console to capture active feature flags, plugin status, migration version, and memory usage.
- **Common Support Queries**:
  - *Holding prices not updating*: Run `REFRESH_PORTFOLIO` from Action Center.
  - *EPF PDF import error*: Verify statement format matches TCS / EPFO standard statement structure.
