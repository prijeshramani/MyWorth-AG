## 1. Beta Protection Principles

Beta Safe Mode guarantees zero accidental data loss when developers or owners test with real Indian financial data:
- Automatic backup before every destructive operation (`db:reset`, bulk delete, import rollback).
- Timestamped restore points saved in `data/backups/`.
- One-click **Restore Last Backup** in Developer Console.
