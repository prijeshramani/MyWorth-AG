# Semantic Versioning & Release Governance

## 1. Version Format
FamilyWealthOS follows Semantic Versioning (`MAJOR.MINOR.PATCH`):
- **MAJOR**: Breaking schema or architecture changes.
- **MINOR**: New phase features, engines, or major capabilities.
- **PATCH**: Bug fixes, performance tweaks, and UI refinements.

## 2. Release Sequence
- `v1.8.0` – Phase 7B.1 AI Wealth Advisor Core & Skill Registry
- `v1.9.0` – Phase 7B.2 AI Actions, What-If Simulation Engine & Action Center
