## 1. Top Navbar Controls

- **Global Search Modal (`Ctrl+K`)**: Opens a modal searching Family Members, Holdings, Policies, Documents, Tax, and Accounts.
- **Dataset Mode Switch**: Toggle between `DEMO` sample data and `REAL` user data workspace.
- **Reporting Currency**: Toggle between `INR (₹)` and `USD ($)`.
- **Onboarding Quick Launcher**: Launches the 8-Step Setup Wizard anytime.

## 2. Navigation Drawer Map

1. **Dashboard** (`/dashboard`): Polished KPI cards, net worth, risk gauge, alerts, and recent activity.
2. **Family & Members** (`/family`): Member management, roles, PAN, Aadhaar link status, and contact info.
3. **Portfolio Tree** (`/portfolio`): Asset class breakdown, portfolio tree nodes, and valuation.
4. **Holdings** (`/holdings`): Asset table view with search and filters.
5. **Transactions** (`/transactions`): Buy/Sell transaction logs.
6. **Bank & Demat Accounts** (`/accounts`): Bank accounts and Demat broker API credentials.
7. **Protection & Insurance** (`/protection`): Life and health insurance summary and family coverage matrix.
8. **Tax Intelligence** (`/tax`): Old vs New Regime comparison, 80C/80D tracker, and compliance calendar.
9. **Document Vault** (`/documents`): Categorized document repository with file upload.
10. **Import Center** (`/import`): CAMS CAS, NSDL/CDSL, Excel, CSV, and broker statement importer.
11. **Data Manager** (`/data-manager`): Pending import reviews, duplicate resolution, and batch rollbacks.
12. **Data Quality Center** (`/data-quality`): Audits for missing PANs, nominees, cost prices, and tax profiles.
13. **Reconciliation Dashboard** (`/reconciliation`): Multi-way matching between broker, portfolio, tax, and bank statements.
14. **Estate & Succession** (`/estate`): Phase 6B Estate module preview badge.
15. **Reports Generator** (`/reports`): Report generator and cash flow statements.
16. **Platform Settings** (`/settings`): Security, password updates, session revocation, and JSON backup exports.
17. **Developer Mode** (`/developer`): DB Table Inspector, API execution logs, migration status, and performance metrics.
