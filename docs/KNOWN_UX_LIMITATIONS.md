# FamilyWealthOS — Known UX Limitations (Phase 7E)

## Documented UX Limitations & Future Work

1. **Browser Offline Mode**: Full offline capability requires local PWA service worker caching (scheduled for Phase 8).
2. **Direct Bank OAuth**: Bank account sync operates via statement file parsing (CSV/Excel) rather than direct Open Banking APIs due to Indian regulatory consent guidelines.
3. **Multi-Currency Real-time FX Rates**: USD conversion currently uses a fixed INR/USD conversion rate (83.50); live FX API sync planned for future release.
