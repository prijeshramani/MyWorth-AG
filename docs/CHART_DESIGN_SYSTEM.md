## 1. Visual Guidelines for Financial Charts

Family Wealth OS charts adhere to standard dark mode visual design tokens:

- **Grid Lines**: Soft slate borders (`rgba(255, 255, 255, 0.05)`) with dashed stroke (`strokeDasharray="3 3"`).
- **Gradient Fills**: Multi-stop linear gradients for Area charts (`#0284c7` to `rgba(2, 132, 199, 0.0)`).
- **Tooltip Container**: Glassmorphism surface (`bg-slate-900/90 border border-slate-700/50 backdrop-blur-md`).
- **Axis Styling**: Clean mono typography (`#64748b` text color, 11px font size).
