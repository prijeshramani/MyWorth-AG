# FamilyWealthOS — Notification Center Design (Phase 7E)

## System Design
- **Lifecycle States**: `NEW`, `READ`, `SNOOZED`, `ARCHIVED`.
- **Alert Categories**: Protection renewals, Tax deadlines, SIP auto-debit alerts, Nominee verification audits, System sync statuses.
- **Action Dispatch**: Direct buttons ("Review Policy", "Optimize Tax", "View Portfolio") navigating directly to target views.
